大白话：App 里网页功能设置得很宽松，但系统层没给相机 / 定位 / 文件这些权限开绿灯，所以实际用不了。这段是别的项目的安全审计，和本页面看动态没有关系。

        


        WebView 四层架构
        
Layer 1 · WebSettings — JavaScript / 文件访问 / 跨域 / 混合内容全开 高危

        
Layer 2 · WebViewClient — URL 零白名单；SSL 走 super 不绕过；仅拦 B 站播放协议

        
Layer 3 · WebChromeClient — 三个权限回调全部未实现 静默拒绝

        
Bridge · window.ipc — 单一 postMessage 入口，无敏感 Native 命令


        权限链路矩阵
        

          
JavaScript可用

          
DOM Storage可用

          
本地文件可用

          
file:// 跨域高危开放

          
URL 导航无白名单

          
混合内容兼容模式

          
SSL 校验有效

          
相机 / 麦克风禁用

          
地理位置禁用

          
文件上传禁用

          
剪贴板 / IntentBridge 无命令

        


        残留风险
        
高R1 setAllowUniversalAccessFromFileURLs(true)：恶意 file:// 页面可跨域读数据

        
高R2 URL 导航无白名单：可跳钓鱼站 / 尝试 intent://

        
中R3–R6 Bridge 分发器过大、无 SafeBrowsing、无多进程隔离、预加载脚本注入

        
低混合内容兼容模式、监控 SDK 行为追踪、B 站协议硬编码


        
静态审计结论，未做动态验证；目标为 3.0.8(367)，与本页请求头 3.1.0 不同源，勿混用。
